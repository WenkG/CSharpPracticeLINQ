\# CSharpPracticeLINQ



Учебный проект на C#, созданный для практики основ программирования, ООП, коллекций, LINQ и Git.



\## Возможности



\- Добавление игроков

\- Поиск игроков

\- Удаление игроков

\- Повышение уровня

\- Фильтрация игроков через LINQ

\- Сортировка

\- Группировка

\- Статистика

\- Работа с Git и GitHub



\## Технологии



\- C#

\- .NET

\- LINQ

\- Git

\- GitHub



\## Цель проекта



Практика C# и постепенное изучение инструментов, используемых в реальной разработке.
